# Security Policy

Quevaa handles sensitive wellness and reproductive-health information, so
security and privacy reports should be handled carefully.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability that could expose
sensitive health data, local database contents, app-lock state, notification
privacy controls, backup files, or other private user information.

Send security-sensitive reports privately to:

kenoyek@gmail.com

Please include:

- A clear description of the issue
- Steps to reproduce, if safe to share
- Affected platforms or versions
- Any proof-of-concept details needed to verify the report
- Whether the issue may expose user health data

## Scope

Security reports may include:

- Local data exposure
- Backup/export encryption issues
- App-lock bypasses
- Notification privacy leaks
- Insecure storage of sensitive values
- Dependency vulnerabilities with practical impact
- Routes or logs exposing private health information

## Public Disclosure

Please give the Quevaa project owner reasonable time to investigate and release
a fix before public disclosure.
